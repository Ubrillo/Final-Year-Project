# Vision-Based Obstacle Avoidance and Autonomous Navigation

A final year dissertation project focused on developing an autonomous robotic navigation system using computer vision, machine learning, and ROS 2. The system integrates a YOLO-based object detection model with a TurtleBot platform to perform real-time obstacle detection and autonomous navigation.

---

## Features

- Real-time object detection using YOLO
- Autonomous obstacle avoidance
- ROS 2 node-based architecture
- TurtleBot integration
- Camera-based environmental perception
- Real-time navigation and movement control

---

## Technologies Used

- Python
- ROS 2
- YOLO
- OpenCV
- TurtleBot
- Gazebo
- RViz
- Ubuntu Linux
